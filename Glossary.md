# Glossary of Key Terms

## A

**AI (Artificial Intelligence)**
The simulation of human intelligence in machines programmed to think and learn.

**Algorithm Bias**
Bias introduced by the algorithm's design or feature selection, independent of the training data.

**Amazon Bedrock**
Fully managed service providing access to foundation models from multiple providers via API.

**API (Application Programming Interface)**
A set of protocols and tools for building software applications and enabling communication between systems.

**Attention Mechanism**
A technique in neural networks that allows models to focus on relevant parts of the input.

## B

**Batch Inference**
Processing multiple inputs at once, typically used for non-real-time predictions.

**BERT (Bidirectional Encoder Representations from Transformers)**
A foundation model designed for understanding text by considering context from both directions.

**Bias**
Systematic errors in AI systems that lead to unfair outcomes for certain groups.

**BLEU Score**
A metric for evaluating the quality of machine-translated text.

## C

**Chain-of-Thought Prompting**
A prompt engineering technique that asks the model to explain its reasoning step-by-step.

**Classification**
A supervised learning task of categorizing data into predefined classes.

**Claude**
Anthropic's conversational AI foundation model available through Amazon Bedrock.

**CloudTrail**
AWS service for logging API calls and actions across AWS infrastructure.

**CloudWatch**
AWS monitoring and observability service for metrics, logs, and alarms.

**Context Window**
The maximum amount of input (in tokens) a language model can process at once.

**Convolutional Neural Network (CNN)**
A type of neural network particularly effective for image processing.

**Cosine Similarity**
A measure of similarity between two vectors based on the cosine of the angle between them.

## D

**Data Bias**
Bias present in training data, often reflecting historical inequalities or unbalanced representation.

**Deep Learning**
A subset of machine learning using neural networks with multiple layers.

**Differential Privacy**
A technique that adds noise to data to protect individual privacy while maintaining statistical utility.

**Diffusion Models**
Generative AI models that create images by gradually removing noise, guided by text prompts.

**DynamoDB**
AWS NoSQL database service with millisecond latency.

## E

**Embeddings**
Numerical representations of data (text, images, etc.) in a multi-dimensional space that capture semantic meaning.

**Encryption at Rest**
Protecting stored data through encryption.

**Encryption in Transit**
Protecting data while it moves between systems using protocols like TLS.

**Epoch**
One complete pass through the entire training dataset.

**Explainability**
The ability to understand and interpret how an AI model makes decisions.

## F

**F1 Score**
The harmonic mean of precision and recall, balancing both metrics.

**Fairness**
The principle that AI systems should treat all individuals and groups equitably.

**Feature**
An input variable used by a machine learning model to make predictions.

**Federated Learning**
Training models across multiple decentralized devices without centralizing data.

**Few-Shot Learning**
Training or prompting a model with only a few examples.

**Fine-Tuning**
Adapting a pre-trained model to a specific task by continuing training on specialized data.

**Foundation Model**
Large AI models trained on broad data that can be adapted for various tasks.

## G

**GDPR (General Data Protection Regulation)**
European Union regulation governing data protection and privacy.

**Generative AI**
AI systems that create new content (text, images, code, etc.) based on learned patterns.

**GPT (Generative Pre-trained Transformer)**
A family of large language models for text generation.

**Guardrails**
Constraints and controls on AI model outputs to ensure safe and appropriate responses.

## H

**Hallucination**
When a language model generates false, nonsensical, or unsupported information.

**HIPAA (Health Insurance Portability and Accountability Act)**
US law governing the privacy and security of healthcare data.

**Hyperparameter**
Configuration settings that control the learning process (e.g., learning rate, batch size).

## I

**IAM (Identity and Access Management)**
AWS service for managing access to resources through users, roles, and policies.

**Inference**
Using a trained model to make predictions on new data.

**IoT (Internet of Things)**
Network of physical devices connected and exchanging data.

## J

**JumpStart**
SageMaker feature providing access to pre-trained foundation models and solutions.

## K

**KMS (Key Management Service)**
AWS service for creating and managing encryption keys.

**k-NN (k-Nearest Neighbors)**
Algorithm for finding the k most similar items, used in vector search.

## L

**Label**
The target variable or correct answer in supervised learning.

**Lambda**
AWS serverless compute service for running code without managing servers.

**Latency**
The time delay between input and response.

**LLM (Large Language Model)**
Large neural networks trained on vast text data for language understanding and generation.

**LoRA (Low-Rank Adaptation)**
An efficient fine-tuning method that updates only a small subset of model parameters.

## M

**Machine Learning (ML)**
A subset of AI where systems learn and improve from experience without explicit programming.

**Macie**
AWS service for discovering and protecting sensitive data in S3.

**Multimodal Models**
AI models that work with multiple types of data (text, images, audio).

## N

**Named Entity Recognition (NER)**
NLP task of identifying entities like names, dates, and locations in text.

**Natural Language Processing (NLP)**
Field of AI focused on enabling computers to understand, interpret, and generate human language.

**Neural Network**
Computing system inspired by biological neural networks, consisting of interconnected nodes.

## O

**OpenSearch**
AWS search and analytics service with vector search capabilities.

**Overfitting**
When a model performs well on training data but poorly on new data.

## P

**Parameter**
Learned values in a model (weights and biases) adjusted during training.

**PEFT (Parameter-Efficient Fine-Tuning)**
Fine-tuning methods that update only a subset of model parameters.

**Perplexity**
A metric measuring how well a model predicts text (lower is better).

**Precision**
The proportion of positive predictions that are actually correct.

**Prompt**
Input text that guides an AI model's output.

**Prompt Engineering**
The practice of designing effective prompts to get desired outputs from AI models.

## Q

**Q (Amazon Q)**
AWS AI-powered assistant for business and development tasks.

## R

**RAG (Retrieval Augmented Generation)**
Combining information retrieval with text generation to produce informed responses.

**Real-Time Inference**
Processing inputs and returning predictions with minimal delay.

**Recall**
The proportion of actual positives that are correctly identified.

**Regression**
A supervised learning task of predicting continuous values.

**Reinforcement Learning**
Learning through trial and error with rewards and penalties.

**Responsible AI**
Developing and deploying AI systems ethically, fairly, and safely.

**ROUGE Score**
Metrics for evaluating text summarization quality.

## S

**S3 (Simple Storage Service)**
AWS object storage service with unlimited scalability.

**SageMaker**
AWS comprehensive machine learning platform for building, training, and deploying models.

**SageMaker Clarify**
SageMaker tool for detecting bias and explaining model predictions.

**Semantic Search**
Search based on meaning rather than exact keyword matching.

**Sentiment Analysis**
Determining the emotional tone or opinion expressed in text.

**Supervised Learning**
Learning from labeled data with known correct answers.

**System Prompt**
Initial instructions that set the behavior and role of an AI model.

## T

**Temperature**
A parameter controlling randomness in model outputs (0 = deterministic, higher = more creative).

**Textract**
AWS service for extracting text and data from documents.

**TLS (Transport Layer Security)**
Protocol for encrypting data in transit.

**Token**
The basic unit of text processed by language models (can be words, subwords, or characters).

**Tokenization**
Breaking text into tokens for processing.

**Top-p Sampling**
Limiting token selection to the most probable tokens that sum to probability p.

**Transformer**
Modern neural network architecture that uses attention mechanisms, foundational for LLMs.

**Transfer Learning**
Using knowledge from one task to improve performance on another related task.

## U

**Underfitting**
When a model is too simple to capture patterns in data.

**Unsupervised Learning**
Learning from unlabeled data to find patterns and structure.

## V

**Vector**
A numerical array representing data in multi-dimensional space.

**Vector Database**
Database optimized for storing and searching vectors (embeddings).

**VPC (Virtual Private Cloud)**
Isolated network environment in AWS.

## W

**WAF (Web Application Firewall)**
AWS service protecting web applications from common exploits.

## Z

**Zero-Shot Learning**
Making predictions without any task-specific training examples.

## Quick Reference: Model Types

| Model Type | Purpose | Example |
|------------|---------|---------|
| LLM | Text generation and understanding | GPT, Claude, Llama |
| Diffusion | Image generation | Stable Diffusion, DALL-E |
| Multimodal | Multiple data types | GPT-4V, Claude 3 |
| Embedding | Convert text to vectors | Titan Embeddings, Cohere |
| Classification | Categorize data | BERT variants |
| Translation | Language translation | mT5, NLLB |

## Quick Reference: Learning Types

| Type | Data | Use Case |
|------|------|----------|
| Supervised | Labeled | Classification, regression |
| Unsupervised | Unlabeled | Clustering, dimensionality reduction |
| Reinforcement | Rewards/penalties | Game playing, robotics |
| Semi-supervised | Partially labeled | When labels are expensive |
| Self-supervised | Creates own labels | Pre-training foundation models |
