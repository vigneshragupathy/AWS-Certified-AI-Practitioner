# AWS Certified AI Practitioner (AIF-C01) - Study Notes

Welcome to the comprehensive study guide for the AWS Certified AI Practitioner certification exam. This repository contains organized notes covering all five exam domains.

## 📋 Exam Overview

- **Exam Code:** AIF-C01
- **Number of Questions:** 65 (50 scored, 15 unscored)
- **Time Limit:** 90 minutes
- **Passing Score:** 700 out of 1000
- **Cost:** $100 USD
- **Question Types:** Multiple choice, multiple response, ordering, matching, and case study

## 📚 Exam Domains

### [Domain 1: Fundamentals of AI and ML](./domain-1-fundamentals-ai-ml/) (20%)
- Core AI and ML terminology
- Natural Language Processing (NLP)
- Inferencing techniques
- Supervised and unsupervised learning
- Deep learning concepts

### [Domain 2: Fundamentals of Generative AI](./domain-2-fundamentals-generative-ai/) (24%)
- Vectors, embeddings, and tokenization
- Large Language Models (LLMs)
- Diffusion and multimodal models
- AWS services for generative AI (Amazon Bedrock, SageMaker)
- Use cases and business value

### [Domain 3: Applications of Foundation Models](./domain-3-applications-foundation-models/) (28%)
- Selecting and applying foundation models
- Model evaluation and optimization
- Prompt engineering
- Fine-tuning techniques
- Real-world deployment on AWS

### [Domain 4: Guidelines for Responsible AI](./domain-4-responsible-ai/) (14%)
- Ethics, bias, and fairness
- Transparency and explainability
- Regulatory compliance
- Risk identification and mitigation
- Business metrics for responsible AI

### [Domain 5: Security, Compliance, and Governance](./domain-5-security-compliance-governance/) (14%)
- AWS shared responsibility model
- Data governance and privacy
- IAM and security best practices
- Compliance standards
- Data lineage and lifecycle management

## 🎯 Target Audience

This certification is ideal for:
- Business analysts
- IT support professionals
- Sales and marketing professionals
- Product/project managers
- Line-of-business managers
- Anyone using AI/ML solutions on AWS

## 🔧 Key AWS Services

Familiarity expected with:
- Amazon Bedrock
- Amazon SageMaker
- Amazon EC2
- Amazon S3
- AWS Lambda
- AWS IAM
- AWS Pricing and operational models

## 📖 How to Use This Guide

1. Review each domain folder in order of your study plan
2. Focus on domains with higher weightage (Domain 3 at 28%)
3. Practice with the provided examples and use cases
4. Review AWS service documentation for hands-on understanding
5. Take practice tests to validate your knowledge

## 🚫 Out of Scope

You are NOT expected to:
- Code or implement AI/ML models or pipelines
- Perform data or feature engineering
- Undertake advanced model tuning
- Develop in-depth security frameworks
